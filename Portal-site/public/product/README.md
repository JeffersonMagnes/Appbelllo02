# Capturas do AppBello

As imagens WebP são capturas dos componentes reais do Portal-site, renderizados localmente com dados inteiramente fictícios. Não representam contas, clientes ou indicadores de produção.

- Dimensões: 1440 × 950 px; preservar proporção, sem esticar ou recortar a interface.
- Fontes: páginas de agenda, clientes, financeiro e produtos, com o layout do dashboard.
- Captura: Chromium headless, idioma pt-BR; serviços de dados substituídos somente no harness temporário de validação. Nenhuma rota de demonstração foi adicionada ao aplicativo.
- Compressão: WebP, qualidade 88.
- A prévia do hero usa o componente AppointmentTile da própria agenda; os números e nomes são ilustrativos.

Ao atualizar as interfaces, renovar as capturas usando um ambiente de demonstração, sem dados pessoais reais.
